# Template visual-system audit

Figma working file: https://www.figma.com/design/nhoSqkb8G0U3kfWBIEfk5X

The Figma file contains the accepted current-state screenshot, a reusable VibeStudio token set, a componentized audit section, and the agreed four-part design decision. Detailed visual panels remain to be added after the Figma Starter-plan MCP call limit resets.

## Overall verdict

The Template structure is clear, but the selected **Visual taste** category currently stores visual knowledge as text-only rules. This makes the screen readable but prevents a creator or agent from seeing the visual standard it is expected to reproduce.

## Step 1 — Review Visual taste

Health: needs a structural improvement.

Evidence: `01-template-visual-taste.png`

Strengths:

- Template is correctly positioned as a reusable creation system rather than a content library.
- Provenance, editing, archiving, categories, and Shared Attention controls are visible.
- The distinction between active rules and suggested improvements is understandable.

Highest-impact issues:

1. Visual rules are represented only as prose, so users cannot judge palette, hierarchy, crop, density, texture, or composition.
2. The Inspiration-derived rule names the source but does not show the source image, weakening provenance and learning.
3. Every rule uses the same text-card treatment, even though identity, voice, examples, and visual taste are different data types.
4. There is no visible bridge from an approved reference to reusable format examples such as carousel covers, body slides, hero images, or Reel frames.

Recommended visual hierarchy:

1. **Visual foundation** — logo/mark, palette, typography, texture, spacing, and composition principles.
2. **Approved references** — real saved images with editable notes describing what to preserve or avoid.
3. **Format recipes** — visual examples for carousel cover, carousel body, hero image, Reel frame, and video overlay.
4. **Do / avoid pairs** — visual comparison cards that make abstract rules immediately testable.

Accessibility limits:

- The screenshot suggests several muted labels may have low contrast, but contrast ratios require browser measurement.
- Keyboard order, focus visibility, image alt text, and modal behavior cannot be confirmed from this screenshot alone.
